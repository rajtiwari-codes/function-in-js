# Simon Says Game

A simple Simon Says Game built using HTML, CSS, and JavaScript.

## Features
- Start game by pressing any key
- Random color sequence generation
- User input through button clicks
- Level increases after correct sequence
- Game over message with score
- Reset game after wrong input

## Technologies Used
- HTML
- CSS
- JavaScript

## Concepts Practiced
- DOM Manipulation
- Event Handling
- Arrays
- Functions
- Random Logic
- setTimeout()
- Game Logic
